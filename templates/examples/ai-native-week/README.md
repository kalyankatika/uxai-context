# One fictional week: AI-native product work

> **FICTIONAL TEACHING EXAMPLE.** Every contributor, PR number, test result, user observation and activity count here is invented. This is **not** Periscope history.

This is a reusable example of how four cross-disciplinary contributors coordinate product development without a separate backlog system. The product scenario is a sample portfolio-management platform, but the routine applies to other initiatives.

**Read in this order:** [Monday–Friday walkthrough](walkthrough.md) → [current view](now.md) → [work record: navigation](work/platform-navigation.md) → [work record: data](work/portfolio-data.md) → [weekly activity](activity.md).

## Equivalent familiar tools

| Need | Current approach | Legacy equivalent |
| --- | --- | --- |
| What matters now and next | One living `now.md` | Kanban / sprint board |
| Context across sessions | `work/<topic>.md` when needed | Epic / Loop page |
| Small independently tracked bug | Existing GitHub Issue, if useful | Ticket |
| Actual implementation/review | Product repo PRs and tests | PR / code review |
| Progress history | Source-linked `activity.md` summary | Status report |

No functional queues, story points, compulsory sprint deadlines, or duplicate Issue states. **One driver keeps the next move clear; all contributors can participate across roles.**

The execution reasoning loop is **Intent → Shape → Plan → Make → Prove → Learn ↺**; it is not six files or approval gates. A week is only a convenient unit for summarizing activity, not a timebox for completing work.

## What's fictional this week?

Four contributors (A: engineering/AI, B: design, C: research, D: product/program) work on navigation and portfolio data. Eight fictional PRs are opened and seven merged. One work record resolves on evidence, the other remains active. Technical tests and a tiny task walkthrough offer different kinds of evidence.

**`now.md` shows Friday's current state.** Monday's state is quoted in `walkthrough.md` only for teaching. In reality the *same* `now.md` is edited in place and Git holds its history.
