**Full walkthrough:** [One fictional week of AI-native product work](examples/ai-native-week/README.md) — generic contributors, work records, current focus, PR activity, and evidence. Not real project history.\n\n## How to use a note template

1. Open the blank template.
2. Copy it into the relevant project folder.
3. Rename it with a short meaningful name.
4. Replace the prompts with the useful context you have.
5. Delete sections that genuinely do not apply.
6. Commit and push.

Recommended filenames:

- `2026-09-27-navigation-decision.md`
- `2026-09-27-research-synthesis.md`
- `2026-09-27-working-session.md`

## How to start another project

Use [`project-starter/`](project-starter/) as the repeatable project structure.

It includes:

- `README.md` — stable project orientation
- `now.md` — current project snapshot
- `project.yaml` — lightweight structured identity
- starter folders for decisions, meetings, research, and prototypes

See [Add a Project](../docs/ADD-A-PROJECT.md) for the full flow.

## Reference examples

Examples are **reference-only** and deliberately generic. They are not actual project records.

Use them to understand the expected level of detail — concise enough to scan, complete enough to be useful later.

> **The template is a guide, not a form.**
