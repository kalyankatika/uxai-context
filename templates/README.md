## How to use one

1. Open the blank template.
2. Copy it into the relevant project folder.
3. Rename the file with a short, meaningful name.
4. Replace the prompts with the useful context you have.
5. Delete sections that genuinely do not apply.
6. Commit and push.

Examples are **reference-only** and are deliberately generic. They are not actual project records.

Keep contributions short enough that someone can understand them quickly.
