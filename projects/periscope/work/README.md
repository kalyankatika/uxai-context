# Periscope Work

This folder is for meaningful active work threads that need evolving context while the work is underway.

Use it when a piece of work is substantial enough that another teammate should be able to understand:

- what we are trying to accomplish
- why it matters
- current thinking
- linked artifacts
- what we are learning
- what happens next

Use the shared [work thread template](../../../templates/work-thread.md) as a starting point.

## One file per meaningful thread

Examples might include:

```text
2026-09-28-context-discovery.md
2026-10-02-relationship-exploration.md
2026-10-08-prototype-evaluation.md
```

Do not create a work thread for every small task.

A thread should represent meaningful work that benefits from durable context.

## How work connects to the rest of the project

```text
active work thread
       │
       ├── learning → research/ or prototype context
       ├── choice   → decisions/
       ├── project change → now.md
       └── reusable part → ../../shared/ only after proven reuse
```

The work folder is not a backlog or replacement for Jira.

It is the evolving context around meaningful work.

When a thread is complete, keep the record if it remains useful. Capture durable outcomes in the appropriate project folders and keep `now.md` current.
