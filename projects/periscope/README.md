## Project overview

Periscope is a local UXD workspace connecting projects, people, reporting relationships, priorities and capacity. It aims to help design leaders understand the portfolio and where attention is needed.

This folder holds intent, current focus, decisions and learning. Implementation and build evidence live in the product repository. The [working loop and activity baseline](operating-model.md) captures the current setup and a proposed lightweight capture cadence.

Keep this section relatively stable. Use [now.md](now.md) for current activity and changing priorities.

## How to contribute

Use the smallest durable update that fits what changed.

| If you need to capture... | Go here |
|---|---|
| Current focus, recent change, blocker, or next step | [now.md](now.md) |
| Important decision | [decisions/](decisions/) |
| Useful meeting outcome | [meetings/](meetings/) |
| Research finding or evidence | [research/](research/) |
| Prototype learning | [prototypes/](prototypes/) |
| Meaningful active work that needs evolving context | [work/](work/) |
| Not sure what format to use | [Templates](../../templates/README.md) |

Keep primary design, code, delivery, and enterprise artifacts in their source systems and link to them from here.

> **Link to the artifact. Capture the context.**

## Kickstarting the project

Periscope is the first project we are using to prove the UX AI Context working pattern.

Start small:

1. keep [now.md](now.md) current
2. create a [work thread](work/) only for meaningful active work
3. capture decisions, research, and prototype learning when they become durable
4. link to source artifacts instead of copying them
5. promote only proven reusable parts into [shared](../../shared/README.md)

We should learn from how the team actually uses this before adding more project structure.
