# Community Governance

This area captures lightweight stewardship principles for what becomes durable or shared UX AI context.

It is **not** intended to govern experimentation.

People should be able to explore, prototype, and share freely.

Governance applies when something is being promoted into canonical project context or the reusable `shared/` layer.

## Stewardship, not bureaucracy

The purpose of stewardship is to maintain signal and trust.

A steward may ask:

- Does this add meaningful context?
- Is the hypothesis or learning clear?
- Is this duplicating work that already exists?
- Is evidence represented accurately?
- Should this stay project-specific?
- Is there actually a reusable part?
- Does it conflict with an authoritative standard?
- Are source links and permissions appropriate?
- Can someone else understand or continue the work?

The goal is curation, not gatekeeping.

## Core principles

> **Participation can be broad. Canonical context should be curated.**

> **Share broadly. Promote selectively.**

> **Promote signal, not activity.**

> **Capture the reusable part, not everything.**

## Possible future model

When participation justifies it, a small set of context stewards could help maintain the quality of promoted content.

Their responsibility would be to:

- help contributors find the right home
- connect duplicate or related work
- preserve provenance
- keep shared context high-signal
- identify useful gaps
- protect source-system permissions
- help promote reusable capability

This should remain lightweight and distributed.

Detailed stewardship roles, review mechanics, moderation, and community governance are intentionally deferred until we have enough real activity to design them well.
